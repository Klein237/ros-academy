# Workspace du module « Rejouer des données avec ros2 bag »

Le package `arret_urgence` y est prêt : le nœud d'arrêt d'urgence du cours, sa décision `detection.py`, et un lidar simulé (`ros2 run arret_urgence lidar_simule`) pour avoir des données à enregistrer. Suivez le cours : enregistrez dans `src/arret_urgence/test/donnees/couloir`, inspectez, rejouez, puis lancez les tests depuis `src/arret_urgence`.
