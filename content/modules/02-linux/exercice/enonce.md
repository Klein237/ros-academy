## « Permission denied »

Le robot de livraison de l'entrepôt s'appelle **livreur-01**. Un collègue vous a laissé son dossier de démarrage, `~/ws/02-linux-exercice`, avec une consigne : « lancez simplement `./demarrer_robot.sh` ». Mais rien ne se passe comme prévu :

```bash
cd ~/ws/02-linux-exercice
./demarrer_robot.sh
# bash: ./demarrer_robot.sh: Permission denied
```

Le script lui-même est correct : **ne le modifiez pas**. Faites en sorte que `./demarrer_robot.sh` démarre le robot **livreur-01**, en lisant attentivement chaque message, puis cliquez sur **Vérifier**.
