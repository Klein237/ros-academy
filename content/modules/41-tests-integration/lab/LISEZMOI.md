# Workspace du module « Tester un nœud avec launch_testing »

Le package `limiteur` y est prêt : le nœud du cours et son test d'intégration. Compilez, puis lancez le test : `colcon build`, `source install/setup.bash`, `launch_test src/limiteur/test/test_limiteur_launch.py`. Ajoutez ensuite vos propres tests dans le même fichier.
