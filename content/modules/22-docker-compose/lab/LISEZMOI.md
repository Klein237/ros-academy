# Lab du module « Plusieurs conteneurs : Compose et DDS »

- `src/livraison_bringup` : le package du robot (le même qu'au module précédent).
- `compose.yaml` : à créer en suivant le cours (bouton « Ouvrir dans le lab »).

Le lab n'a pas Docker. Sur une machine où il est installé, avec l'image du module précédent :
`docker compose up` depuis ce dossier.
