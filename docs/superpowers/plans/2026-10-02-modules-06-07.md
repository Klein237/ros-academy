# Modules 06 (paramètres et launch) et 07 (TF2) — Plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal :** prolonger le parcours « ROS 2 Fondamentaux » avec deux modules, sur le même fil rouge (le robot à conduite différentielle) et le même format : cours avec lab guidé, exercice construit autour d'une vraie panne, QCM.

**Modules :**

- **06-parametres — Paramètres et fichiers launch** (coef 2) : paramètres déclarés (types, description, lecture seule), validés à chaud (`add_on_set_parameters_callback`), `ros2 param`, fichier YAML, fichier launch avec argument, installation par `setup.py`. **Panne** : la clé de premier niveau du YAML (`diff_drive:`) ne correspond pas au nom du nœud ; le fichier est ignoré sans message et le robot garde sa vitesse par défaut.
- **07-tf2 — Repères et transformations avec TF2** (coef 2) : arbre `odom → base_link → laser`, quaternions (demi-angle), `TransformBroadcaster`, `static_transform_publisher` dans le launch, `Buffer` / `TransformListener` dans un nœud `obstacle_locator` qui place un obstacle vu par le laser dans `odom`. **Panne** : conversion yaw → quaternion sans le demi-angle ; tout est juste en ligne droite, l'obstacle est mal placé après un virage.
